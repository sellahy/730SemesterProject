# Gesture-Recognition

Smart ring for Bluetooth device control

Technical Aspects:

    Board used: AITRIP ESP32-C3 MINI Development Board
    Accelerometer: Adafruit LSM6DS3TR-C 6-DoF Accel + Gyro IMU
    IDE: PlatformIO through VSCode
    Coding Language: C++
    Processor: ARM
